# BaaDash 浏览器下载助手 · 商店介绍草稿

此文档仅供未来提交使用，不代表已上架。沿用当前原生消息主机与扩展标识；正式上架前需确认标识归属、签名及各平台的隐私表单。

## 名称

BaaDash 下载助手

## 简介

将普通下载交给 BaaDash，并在需要时选择视频、图片和流媒体。资源嗅探与网页按钮分别控制，图片浮层默认关闭。需要配套桌面应用。

## 功能

- 接管普通浏览器下载，传递下载所需的 Cookie、来源页与用户代理。
- 检测当前页面加载的视频／音频资源，通过浮层或扩展弹窗主动下载。
- 独立控制嗅探、视频按钮与图片按钮，支持对单个网站停用。
- 图片右键下载、当前页面图片收集、当前 Pixiv 作品及视频另存 GIF。
- 不抓取作者全部作品，不支持 DRM 或绕过站点权限。

## 数据使用说明草稿

扩展会在本地处理当前页地址、检测到的媒体地址，以及下载必要的 Cookie 等请求信息，并通过原生消息传给用户电脑上的 BaaDash。资源列表保存在浏览器会话存储，偏好保存在浏览器同步存储。桌面应用可能保存任务地址与未完成下载所需的请求信息，以便续传；具体行为见源码。

不应声称“所有信息始终不会离开浏览器”或“应用只连接资源服务器”：用户发起的下载会请求目标站点，更新检查及工具下载也可能访问发行服务。正式提交前需逐项核对权限与当前实现。

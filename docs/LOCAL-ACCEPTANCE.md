# BaaDash 本地施工验收记录

本记录保存发布前的本地验收结果。v0.1.0 以本仓库发布，原生编译与测试结果以对应 GitHub Actions 运行记录为准。

## 已验证

- TypeScript 类型检查及 Vite 生产构建通过。
- 12 项界面与扩展 DOM 场景通过，详见 tools/ui/test-results.json。
- 后台嗅探开关的模拟 API 测试通过：关闭不采集、关闭清旧数据、单站点停用不采集。
- 官网三页在 390px / 1440px 下无横向溢出、无缺图，README 图片路径有效。
- SVG / PNG / ICO / ICNS / BMP 格式检查通过，详见品牌目录 validation.txt。
- 本轮重拍 31 个捕获文件，涵盖全部 21 张原演示图，并新增多选、更新与扩展偏好展示；网站图库同步。捕获清单在 tools/ui/capture-manifest.json。
- 六个演示视频关键帧可渲染；未声称已生成完整 MP4。
- 修改的 Rust 源码通过 tree-sitter 语法解析。语法解析不等于编译、类型检查或运行测试。

## 尚未完成的原生验收

当前主机没有 Rust / Cargo 工具链，因此 cargo test --workspace、原生应用编译和安装升级未执行。新增的断点文件校验／区间测试及本地 HTTP 集成测试已写入源码，但没有运行。

真实 Chrome / Firefox 扩展加载、原生消息主机通信、实际站点视频嗅探、Windows/macOS/Linux 安装包与系统图标缓存仍需实机测试。现有浏览器测试使用 API 模拟，不能替代上述验收。CI 已补上 Windows 原生检查与界面检查配置，尚未触发远程运行。

## 本轮功能范围

嗅探及浮层独立开关、静止隐藏、封面排除、图片默认安静模式、单站点偏好；设置关闭、多选与批量管理、保留文件的历史清理、手动更新入口；分段与续传校验、保存失败提示；MONO 图标与 C 字标、全部演示图、README 和官网介绍。

链接替换续传、拖动队列排序、下载后关机等额外建议不属于已完成项目。后台更新来源已随仓库迁移指向 BaaDash。

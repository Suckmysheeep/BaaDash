v0.2.0 · 2026-11-11

修复

  • GIF 转换结果单独列入已完成记录，可直接打开 GIF 或定位文件，保留原视频或 ZIP。
  • 扩展安装指南展示和复制普通 Windows 路径，正确处理 \\?\ 和 UNC 路径。
  • 吸收上游 Google Drive 分享链接转换、网页误下载识别、扩展接管前探测与浏览器回退。
  • 视频流优先选择最近播放的资源；改进 yt-dlp 原始字节读取及 Windows 管道，明确提示过期链接。
  • 保留已有分段响应、续传验证、中文文件名、图片和 GIF 功能。

新增

  • 跟随系统代理，支持手动 HTTP / SOCKS5 代理及本地网络 IP 绑定；网络设置重启生效。
  • 可选 SHA-256 整文件校验、替换普通文件失效链接后安全续传。
  • 队列位置、下一个下载、失败后使用浏览器下载、托盘限速切换。
  • 批量链接范围展开，如 file[01-50].zip，最多 500 个。
  • 界面缩放 90–150%、可选剪贴板监视、队列定时开始和全部成功完成后的一次性退出／休眠／关机。

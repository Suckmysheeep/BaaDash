v0.4.0 · 2026-11-12

界面重构

  • 采用石墨黑与中性灰阶、品牌荧光绿，保留羊头图标，应用名称使用字体排版。
  • 重做紧凑任务工作区与专业数据表，直接展示大小、进度、速度、剩余时间和连接数，完整保留七类文件分类。
  • 主界面恢复真实网速曲线与多连接点阵；点阵按各连接的实际分段范围绘制，不填充虚构数据。
  • 设置改为应用内页面，左上角返回列表；未保存更改可保存离开、放弃或继续编辑。
  • 使用太阳／月亮切换主题，新增紧凑／标准密度和减少动态效果设置；旧用户自选强调色继续保留。
  • 窗口圆角由原生窗口管理：Windows 10/11 使用实际窗口区域裁切；独立窗口移除透明阴影边距。
  • 保留下载核心、图片/Pixiv/GIF 独立记录、媒体与种子下载、浏览器集成、续传和校验能力。

修复与交互

  • 下载确认与进度弹窗按内容自动调整窗口高度，展开高级选项时整窗长高，不再出现内部滚动条。
  • 修复无边框窗口拖动与边缘缩放逻辑，外部圆角与内部视图统一。
  • 重做窗口缩放适配：拉到最小高度不出现滚动条，最大化时表格与面板填满可用空间。
  • 没有下载任务进行时自动收起实时网速曲线与多连接点阵，任务恢复后展开。
  • 修复已下载／大小列的对齐与单位显示。

工程与发布

  • 工程层统一改名：crate 与可执行文件 baadash、应用标识 com.baadash.app、原生消息主机 com.baadash.host、Firefox 扩展 ID baadash@baadash.app；Chromium 扩展密钥保留，扩展 ID 不变。
  • 首启动自动迁移：旧 com.swiftdl.app 数据目录（设置、历史、缓存与 WebView 配置）整体迁入新标识目录，旧原生消息主机与种子/磁力注册一并清理；旧版续传文件（.swiftdl）仍可恢复。
  • 扩展发行包改名 baadash-extension.zip 与 baadash-firefox.xpi，安装包沿用 BaaDash_* 命名。
  • 仓库精简：宣传视频、品牌设计素材、商店上架材料与 agent 过程文档移出开源仓库（本地归档）；保留官网、界面截图重拍与交互测试工具链。
  • README 与官网演示图统一为深色主题，窗口截图内置 12px 圆角，与官网展示一致。
